# Note di validazione DCAT-AP_IT

Il file `dcat-ap_it.ttl` è una descrizione locale di progetto costruita sul checkpoint. Le proprietà obbligatorie principali (titolo, descrizione, publisher, distribuzioni, licenza, lingua, frequenza) sono presenti. Le `downloadURL` usano volutamente URI `file:` perché il repository non è pubblicato sul Web; prima di una pubblicazione DCAT-AP_IT reale devono essere sostituite con URL HTTPS stabili e il namespace `.invalid` deve essere migrato a un dominio controllato. Non è stato eseguito un validatore remoto DCAT-AP_IT in questa fase.
