# Competency Questions - Biblioteche Fantasma

The competency questions (CQs) guide the RDF model and the SPARQL queries. The narrative term “Biblioteche Fantasma” is not treated as an administrative class or official status.

| CQ  | Question                                                                                                                                         | Required entities/properties                                                                                          | Temporal/semantic constraint                                                                                                                                                                                                      |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| CQ1 | Which temporarily closed libraries are located in a given region?                                                                                | `cis:Library`, `bf:LibraryStatusObservation`, SKOS status, `cis:hasSite/cis:hasGeographicalLocation`, `bf:regionName` | Status observed at the ICCU 2026-09-08 snapshot; does not imply the start date of the closure.                                                                                                                                    |
| CQ2 | Which inaccessible libraries have special collections?                                                                                           | `cis:Library`, `bf:LibraryStatusObservation`, `bf:SpecialCollection`, `cis:hasCollection`                             | “INAGIBILE” remains distinct from suspension due to earthquake and partial reopening.                                                                                                                                             |
| CQ3 | In which municipality is a library located?                                                                                                      | `cis:Library → cis:hasSite → cis:Site → cis:hasGeographicalLocation → bf:Municipality`                                | The municipality is identified by a 6-digit ISTAT code preserved as a string.                                                                                                                                                     |
| CQ4 | Into which library did a given library merge?                                                                                                    | `bf:mergedInto` between two `cis:Library`                                                                             | Relation asserted only for a parsed target ISIL present in the snapshot; 90 records without a target remain without an edge.                                                                                                      |
| CQ5 | Which libraries with service interruption are located in municipalities with population decline from 2019–2025?                                  | SKOS status + municipality + two `bf:DemographicObservation`                                                          | The comparison uses observations from 2019-01-01 and 2025-01-01; Trapani/Misiliscemi remain non-comparable when the 2019 value is missing.                                                                                        |
| CQ6 | Which libraries hold a given type of holdings?                                                                                                   | `bf:HoldingObservation`, `bf:materialType`, SKOS concepts                                                             | The holdings row is an observation from the snapshot, not a `cis:Collection`, in order to avoid improper equivalences.                                                                                                            |
| CQ7 | Which local libraries are linked to external resources?                                                                                          | `rdfs:seeAlso`, `owl:sameAs`/other mappings in the links graph                                                        | ICCU pages are external documents (`rdfs:seeAlso`), not equivalent RDF entities.                                                                                                                                                  |
| CQ8 | What is the distribution of statuses by region?                                                                                                  | status observations + municipality + `bf:regionName` + aggregation                                                    | Distinct count by library; the ICCU NULL remains `NESSUNO_STATO_SPECIALE_REGISTRATO`.                                                                                                                                             |
| CQ9 | Which municipalities with high demographic loss have the highest share of library records with an ICCU status included in the problematic scope? | `bf:populationChangePercent2019_2025`, status observations, municipality                                              | “Problematic” follows exclusively the `include_in_main_analysis=True` criterion defined in the cleaning pipeline. The “high loss” threshold must be passed as an explicit filter in the query and is not encoded in the ontology. |

## RQ coverage

The CQs cover RQ1–RQ5 and RQ7 in the knowledge graph; CQ7 supports RQ6 on interlinking. The age structure (secondary RQ8) is represented in the demographic observations (`population0_14`, `population15_64`, `population65Plus`, `share65Plus`) and is statistically analyzed through the relationship between `share65Plus` and the share of library records with an ICCU status included in the problematic scope; the results are reported in `reports/analysis_tables/age65_problematic_correlation.csv` and in the visualization `visualizations/age65_scatter.png`.
