# 5-Star Open Data Assessment - Biblioteche Fantasma

## Assessment scope

The assessment considers both the technical characteristics of the artifacts and
their actual publication on the Web.

The Web publication is available at:

`https://ameliamorsellino.github.io/biblioteche-fantasma/`

The complete RDF knowledge graph is distributed as a GitHub Release asset at:

`https://github.com/ameliamorsellino/biblioteche-fantasma/releases/latest/download/data.ttl`

The main evidence used is:

* `metadata/licenses.md`;
* `metadata/source_manifest.csv`;
* the processed CSV datasets;
* `ontology/ontology.ttl`;
* `rdf/data.ttl`;
* `rdf/links.ttl`;
* `rdf/metadata.ttl`;
* the RDF and SHACL validation results;
* the interlinking report;
* the SPARQL queries and their results;
* the GitHub Pages publication generated by `scripts/build_web_publication.py`;
* the GitHub release `v1.0.0`.

## Web publication

The public namespace is:

`https://ameliamorsellino.github.io/biblioteche-fantasma/`

The GitHub Pages deployment is automatically generated by the project's Web
pipeline. HTML pages are generated for:

* 19,611 libraries;
* 7,896 municipalities;
* 27,507 core entities overall.

Examples of Web resources:

* `https://ameliamorsellino.github.io/biblioteche-fantasma/resource/library/IT-RM0267/`
* `https://ameliamorsellino.github.io/biblioteche-fantasma/resource/municipality/058091/`

The following are also published:

* Turtle and RDF/XML ontology;
* DCAT metadata;
* `rdf/links.ttl`;
* `rdf/metadata.ttl`.

The complete `data.ttl` knowledge graph is distributed through GitHub release
`v1.0.0`. The published asset has a size of 380,296,920 bytes and digest:

## Interlinking

The pipeline generates links based on official identifiers rather than
fuzzy matching:

* libraries toward ICCU: **19,611/19,611 = 100%**;
* municipalities toward Linked ISPRA: **7,893/7,896 = 99.9620%**.

The three municipalities without `owl:sameAs` are retained as temporally
motivated non-matches instead of forcing semantically incorrect links.

Linked ISPRA URIs are constructed deterministically from the ISTAT code
according to the documented URI policy. The percentage represents
link-generation coverage; the offline pipeline does not perform an individual
HTTP check of all 7,893 targets.

## Static publication limitations

The publication uses GitHub Pages and therefore does not implement a dynamic
Linked Data server with full content negotiation based on the HTTP
`Accept` header or custom 303 redirects.

The core library and municipality entities have public HTML representations.
Other internal knowledge graph resources, such as status observations,
holdings, address and geometry, have HTTPS URIs in the graph but do not
necessarily have a dedicated HTML page.

The complete knowledge graph and RDF distributions nevertheless remain
accessible through public Web URLs.

## SPARQL

The 11 SPARQL queries are executed locally with PyOxigraph.

The project does not publish a public SPARQL endpoint. This is an architectural
choice and does not prevent achievement of the fifth level of the 5-star
model: the central requirement of level 5 is linking local data to other
data on the Web.

## Final assessment

The published version of the project satisfies all five levels of the
5-star Open Data model: open data on the Web, structured data, open formats,
HTTP(S) identifiers and links to external resources.

This statement does not imply that the project implements every possible
feature of a server-side Linked Data platform: full content negotiation,
a public SPARQL endpoint and dedicated HTML representations for every internal
URI remain possible extensions.
